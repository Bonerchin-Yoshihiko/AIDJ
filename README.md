# Miso Soup

曲ごとに「ここを聴かせたい！」という範囲を指定すると、テンポを揃えてつないだミックスを書き出します。

## Windows 版をダウンロードする

1. このリポジトリの **Releases** から `Miso-Soup-windows.zip` をダウンロード
2. 右クリック →「すべて展開」して、中の **Miso Soup.exe** をダブルクリック
   - 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
   - うまく動かないときは `%TEMP%\miso-soup.log` にログが残っています

main に push するたびに、GitHub Actions が exe を作って動作テストし、テストが通ったら Releases に新しい版（v0.1.番号）を載せます。

同梱している rubberband（高音質なテンポ調整）は GPL ライセンスです。アプリを人に配るときは注意してください。

## セットアップ

```bash
pip install -r requirements.txt
# 任意: 高音質なテンポ調整のために rubberband を入れる（なければ librosa で代用）
#   Mac: brew install rubberband   Ubuntu: sudo apt install rubberband-cli
```

## アプリとして使う

```bash
python app.py            # アプリのウィンドウが開く
python app.py --browser  # ウィンドウが開けないときは、いつものブラウザで
```

1. 曲をウィンドウにドラッグ＆ドロップ（mp3 / wav / flac / ogg）
   - WAV は 16/24/32bit・浮動小数点・ADPCM 圧縮・48kHz/96kHz・ヘッダーが壊れたものも読める
   - 読めないときは理由が表示される（例: 拡張子が .wav でも中身が m4a のとき）
2. 波形の上をドラッグして聴かせたい範囲を選ぶ（最初は一番盛り上がっている部分が仮に選ばれている）
   - 範囲の端をドラッグで伸び縮み、内側をドラッグで移動、開始・終了の欄に時刻を直接入れてもOK
   - 「▶ 範囲を試聴」で選んだ部分だけ再生、ループで範囲をくり返し
   - ↑↓ で順番を入れ替え、⧉ で同じ曲を別の範囲でもう一度使う
3. 「ミックスする」→ 下にミックスの波形が出る。色の帯がそれぞれの曲の範囲
4. 「保存する」で wav か mp3 に書き出し

### つなぎのビート生成（ブリッジ）

テンポやキーが大きく違う曲の間に、両方をつなぐ数小節のビートを自動で作って挟みます。

- 前の曲のテンポ・キーで始まり、テンポを少しずつ変えながら転調して、次の曲のテンポで終わる
- コードは「前の曲の主和音 → 両方のキーに共通するコード → 次の曲の下属和音 → 次の曲の属和音」と進むので、次の曲に自然に入れる
- 最初と最後の数小節はテンポを固定してあり、前後の曲とビートを合わせて重なる
- 最後の1小節はスネアロールとライザー（だんだん高くなるノイズ）で盛り上げる
- 設定の「つなぎのビート生成」で、合わないときだけ（既定）／いつも／しない を選べる
- キーは自動で推定する（平行調、たとえば C メジャーと A マイナーを取り違えることはある）

#### 曲のパートでブリッジを作る（AI のパート分け）

曲と曲の間の「ブリッジの素材 ▸」を開くと、前の曲・次の曲の **ドラム／ベース／ボーカル／その他** を選べます。
選んだパートは AI（Meta の Demucs）で曲から取り出し、ブリッジのテンポの変化に合わせて伸び縮みさせて使います。

- ドラム: 片方の曲だけ選ぶとブリッジの最後まで鳴らし、両方選ぶと真ん中で入れ替える
- ベース・その他（パッド・リード・シンセなど）: キーがあるので、前の曲は前半、次の曲は後半だけ
- ボーカル: 範囲の端の1小節を切り出して繰り返す（ボーカルチョップ）。前の曲はエコーで消えていき、次の曲は最後に向けて大きくなり、最後の1小節は細かく繰り返して盛り上げる
- 「合成音」を切ると、曲のパートだけでブリッジを作る（パートと同じ種類の合成音は自動で外れる）
- パートを選んだつなぎには必ずブリッジが入る。AI のパート分けに1曲あたり数十秒かかる
- パッドとリードは AI でも分けられないので「その他」にまとめている

開発環境で使うときは `pip install -r requirements-ai.txt && pip install --no-deps demucs==4.1.0` のあと、
[htdemucs のモデル](https://dl.fbaipublicfiles.com/demucs/hybrid_transformer/955717e8-8726e21a.th) を `models/htdemucs.th` に置きます。

### 配布用のアプリにする（.exe / .app）

```bash
pip install pyinstaller
python build.py
```

- Windows なら `dist/Miso Soup/Miso Soup.exe`、Mac なら `dist/Miso Soup.app` ができる（その OS の上で実行する）
- rubberband の実行ファイルをアプリと同じフォルダに置くと、高音質なテンポ調整が使われる
- Mac で「開発元を確認できない」と出たら、右クリック →「開く」

## 使い方

```bash
python aidj.py "曲A.mp3@1:05-2:10" "曲B.mp3@0:45-1:20x2" "曲C.mp3@2:00-" -o mix.wav
```

| 書き方 | 意味 |
|---|---|
| `曲.mp3@1:05-2:10` | 1分5秒〜2分10秒を使う |
| `曲.mp3@65-130` | 秒数でもOK |
| `曲.mp3@1:05-` / `曲.mp3@-2:10` | そこから最後まで / 頭からそこまで |
| `曲.mp3@1:05-1:20x4` | 範囲を4回ループ（範囲内リミックス） |
| `曲.mp3` | 曲全体 |

オプション:
- `--bars 4`: つなぎの長さ（小節、既定 8）
- `--bpm 128`: ミックス全体のテンポを固定（省略すると自動）
- `--max-stretch 0.1`: テンポを変えてよい最大の割合（既定 0.15 = ±15%）

同じ曲を範囲を変えて何回入れても構いません（1番のサビ → 別の曲 → 同じ曲の大サビ など）。

## しくみ

1. **ビート解析**: 拍を検出して等間隔の格子に当てはめる。裏拍につられて半拍ずれないよう、キックの位置で表拍を決め直す
2. **範囲を拍に合わせる**: 指定した開始・終了を一番近い拍に寄せる（多少ずれた時刻を入れても大丈夫）
3. **テンポを揃える**: できるだけ多くの曲を小さい変化で揃えられるテンポを選び、各曲を伸び縮みさせる（倍・半分のテンポも同じ仲間として扱う）
4. **つなぐ**: 指定した範囲には手を加えない。前の曲の範囲の**後ろ**と次の曲の範囲の**前**を重ね、ベースを途中で入れ替えるクロスフェードでつなぐ
   - テンポが揺れる曲（クラシック、弾き語り、ライブ音源など）や、テンポ差が大きすぎる曲、範囲の前後に余白がない曲は、エコーアウトで切り替える
5. 曲ごとの音量差をならして書き出す

## 範囲の選び方のコツ

- 開始はサビ頭など**フレーズの1拍目**にすると、つなぎがきれいにはまります（小節の頭までは自動で判定しません）
- つなぎは範囲の外側で行うので、次の曲の範囲の前（Aメロ後半など）が聞こえてきます。前の部分を聞かせたくなければ `--bars` を小さくしてください
